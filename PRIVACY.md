# Privacy policy — A3 Assistant (course project)

A3 Assistant is a student project for USC CSCI 599 (Fall 2026). It is used only with a dedicated test
Google account containing synthetic data.

- **Data accessed:** Gmail messages (read, create drafts) and Google Calendar events (read) of the test
  account that signed in.
- **Use:** only to answer the account owner's requests, prepare briefings, alerts and email drafts.
- **Storage:** no email or calendar content is stored outside the owner's private Google Cloud project;
  logs contain no message text. Nothing is sold or shared with third parties.
- **Sending:** emails are only sent after explicit human approval, to an allowlist of test addresses.
- **Removal:** revoke access at https://myaccount.google.com/permissions at any time.

Contact: via the GitHub repository issues page.
